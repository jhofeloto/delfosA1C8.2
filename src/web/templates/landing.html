Biomarcadores de Riesgo de Diabetes de talla mundial

Modelos validados que estiman glucosa en ayunas y categorizan el estado glucémico con explicabilidad y APIs listas para integrar.

Probar ahora

Fundamento clínico

  • Predicción de glucosa en mg/dL a partir de variables clínicas básicas (edad, IMC, PA, cintura).
  • Clasificación: normal (<100), prediabetes (100–126), diabetes (>126).
  • Datos sintéticos con distribución realista para desarrollo; adaptable a datos reales.
  • Métricas reportadas: R², RMSE, MAE, sensibilidad por clase.

Fundamento técnico

  • Modelos de ML: Linear/Ridge, Random Forest, Gradient Boosting, SVM, MLP.
  • Pipeline: preprocesamiento, ingeniería de variables, escalado, validación cruzada.
  • API: FastAPI + Uvicorn. UI ligera con HTML/JS y plantillas Jinja2.
  • Contenedores: Docker y docker-compose, listo para K8s y CI/CD.

Uso individual

Enviar JSON al endpoint /api/v1/predict con el modelo elegido.

Uso masivo

Subir CSV al endpoint /api/v1/predict/batch o vía UI.

Integración API

OpenAPI interactivo en /docs y contrato predecible para integraciones.

Buenas prácticas y cumplimiento

  • Separación de datos sensibles y modelos. Versionado de modelos.
  • Validación de entrada y manejo de errores con códigos HTTP claros.
  • Listo para autenticación (OAuth/JWT) y auditoría en entornos regulados.
