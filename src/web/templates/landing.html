Biomarcadores predictivos para Diabetes Tipo 2

Predicción de glucosa en ayunas y clasificación del estado glucémico con modelos validados, API robusta y UI lista para clínica e integración.

Probar demo Explorar API

Fundamento clínico

  • Estimación de glucosa (mg/dL) con variables accesibles: edad, IMC, PA, perímetro abdominal.
  • Categorización: Normal (<100), Prediabetes (100–126), Diabetes (>126).
  • Métricas reportadas: R², RMSE y MAE. Sensibilidad por clase en análisis avanzado.

Fundamento técnico

  • Modelos: Linear/Ridge, Random Forest, Gradient Boosting.
  • Pipeline: preprocesamiento, ingeniería de variables, escalado y validación cruzada.
  • Entrega: FastAPI + Uvicorn, plantillas Jinja2, Docker/Compose. Listo para K8s.

Uso individual (JSON)

curl -X POST \
  "{ORIGIN}/api/v1/predict?model=random_forest" \
  -H "Content-Type: application/json" \
  -d '{
    "edad":55, "talla":165, "peso":70, "imc":28.5,
    "tas":135, "tad":85, "perimetro_abdominal":95,
    "puntaje_total":10, "riesgo_dm":0.5
  }'

Uso masivo (CSV)

Cabeceras requeridas:

edad,talla,peso,imc,tas,tad,perimetro_abdominal,puntaje_total,riesgo_dm 
curl -F "file=@lote.csv" \
  "{ORIGIN}/api/v1/predict/batch?model=gradient_boosting"

Buenas prácticas y cumplimiento

  • Validación sólida de entrada y manejo de errores explícitos.
  • Listo para autenticación (OAuth2/JWT) y auditoría en entornos regulados.
  • Versionado de modelos con métricas publicadas; monitoreo y detección de drift (roadmap).
